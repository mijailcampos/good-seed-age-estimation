# Data access

The dataset was supplied through the TripleTen course. It is not bundled here, and no permission to redistribute it is asserted. Obtain it through authorized course access. Do not substitute a similarly named dataset if you want to compare against the recorded metrics.

Run Jupyter from the repository root and arrange the files as follows:

```text
data/
  faces/
    labels.csv
    final_files/
      <image files referenced by labels.csv>
```

The `data/` directory is ignored by Git. The notebook retains selected aggregate outputs from the historical execution so its analysis can be reviewed without downloading the data.
